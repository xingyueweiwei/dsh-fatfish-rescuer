🐋 大肥鱼救星 v5.0 —— 快速上手（30 秒版）
================================================

这是什么？
  DSH（DeepSeek Harness）出毛病时的救援工具：
  打不开、很慢、一直弹黑窗、界面错乱、配置被改坏 —— 点按钮就能修。

怎么用？
  1. 解压到任意目录（不用安装）
  2. 双击「大肥鱼救星.exe」
     ※ Windows 提示"已保护你的电脑"时：点「更多信息」→「仍要运行」
  3. 顶部显示当前状态；下方文本框是日志
  4. 按症状点按钮：

     ▸ 打不开 / 白屏        → 🔍 运行诊断 → ❓ 为何打不开 → 🩺 一键修复
     ▸ 能开但要等很久      → 🚦 启动链路自检 → 🧩 补丁体检
     ▸ 一直弹 PowerShell   → 🔔 弹窗体检 → 🧩 补丁体检 → 🖥 默认终端
     ▸ 界面乱/插件崩       → 🧩 插件兼容性 → 🚨 排查崩溃插件
     ▸ 插件报需要构建授权  → 🔍 研究插件（先给你一份预演，确认后才改配置）
     ▸ 配置被改坏          → 📚 快照列表 → ♻ 恢复配置
     ▸ 日常看看            → 🔄 刷新状态 / 📄 打开日志

  不知道该点哪个？就先点「🔍 运行诊断」，它会告诉你下一步点哪个。

安全吗？
  ✅ 不联网、不上传
  ✅ 不删你的文件（只动它自己目录里的临时日志）
  ✅ 配置改动全部：原子写 + 写后校验 + 失败自动回滚，且改动前自动打快照
  ✅ 会重启/停止服务的按钮都有确认框
  ✅ 「🛡 只诊断」是「让它别乱动」的闸门：开着之后绝不结束、绝不启动任何 dsh 进程
     （🔍 研究插件这类会动手的动作也会被直接拒绝，一个字节都不写）
  ⚠️ 「🔍 研究插件」会在你的真实 profile 里跑一次 pnpm install ⇒ 插件目录会按新配置重装一次；
     它不会结束、也不会重启正在运行的 DSH（改动前先备份，复验不过自动回滚）
  ⚠️ 它会为「补丁体检」修改 DSH 内部的 node_modules 文件（这是治"弹黑窗"用的，升级后会被覆盖）
  ⚠️ 只有点「🖥 默认终端」时才会动注册表（HKCU\Console\%%Startup 一个键）

要求？
  Windows 10/11 + 你机器上已经装过 DSH。不需要 Python / Node / 管理员权限。

出问题怎么反馈？
  点「📦 导出诊断包」→ 把生成的目录打包发出去（已自动隐去你的用户名和路径）。
  日志和快照都在：%USERPROFILE%\.dsh\big-fat-fish-rescuer\

详细说明：看同目录的「使用说明.md」和「安全说明.md」
卸载：删掉整个文件夹即可（想彻底干净，再删 %USERPROFILE%\.dsh\big-fat-fish-rescuer\）
